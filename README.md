# Synthetic Coffee Health Analysis

## Overview
This project analyzes a **synthetic dataset** that simulates the relationship between **coffee consumption** and **health indicators** such as sleep quality, stress level, and productivity.  
The goal is to explore trends and visualize correlations using Python data analysis tools.

## Tools & Libraries
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn 

## Dataset
The dataset is synthetic and includes features such as:  
- `Coffee_Intake` — cups per day  
- `Sleep_Hours`  
- `Stress_Level`  
- `Health_Score`  
- `Age`, `Gender`, `Occupation`, etc.  

## Key Tasks
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Correlation and trend visualization  
- Basic modeling or clustering (optional)
